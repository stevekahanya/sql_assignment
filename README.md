
A structured SQL project designed to create, manage, and query a student information system. This project demonstrates proficiency in Database Management Systems (DBMS), including table creation, data manipulation (DML), and complex querying.

##  Project Objective
The primary goal of this project is to implement a robust `students` database using SQL. It covers:
* **Schema Design:** Defining appropriate data types and constraints.
* **Data Entry:** Populating records with unique identifiers.
* **Data Analysis:** Executing queries for filtering, sorting, and aggregating data.
* **Schema Evolution:** Modifying existing tables using `ALTER` commands.
